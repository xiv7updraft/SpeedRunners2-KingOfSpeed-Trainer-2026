## 🔥 Project Overview

**This tool** is a comprehensive trainer for **SpeedRunners 2: King of Speed**. This unofficial trainer provides optional gameplay adjustments for local races, practice sessions, and offline play. It can modify movement speed, boost resources, jump behavior, item availability, and race survival mechanics while leaving the core platform-racing gameplay intact.

**Target Audience:** Players who want to practice movement, learn maps, test grappling routes, experiment with pickups, create unusual local challenges, or explore the game's mechanics outside competitive online play.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Start the game and load a practice, local, or private race before activating movement options. Use speed and boost controls carefully when approaching jumps, wall jumps, hazards, and shortcuts. Grapple assistance is intended for practicing blue-ceiling grapple points and swing timing rather than replacing route knowledge.

### Tools & Inventory

The game uses race pickups rather than a traditional inventory. Runners normally hold one item at a time. Unlimited pickup and cooldown options affect the currently held race item and can be used to test missiles, traps, freeze rays, golden grappling hooks, blasters, and portable teleporters.

### World & Environment

Use the trainer on the game's map layouts to study booster pads, hazards, levers, wall-jump sections, grapple points, and alternate routes. No open world or traditional exploration system is present; the relevant game environment consists of side-scrolling race tracks and campaign stages.

### Combat & Weapons

Combat is integrated into competitive racing through offensive and defensive pickups. Item controls can help test projectile timing, trap placement, freezing effects, golden grapple interactions, blasters, and teleporters. For fair play, restrict these options to offline practice or agreed private matches.
